# Online Retail Sales Analytics | SQL Data Analytics Project

## 📌 Project Overview

This project analyzes online retail sales data using SQL to identify revenue trends, customer behavior, product performance, and country-wise sales performance.

The project follows a structured data analytics workflow:

**Bronze → Silver → Gold**

The objective is to transform raw retail transaction data into clean, analysis-ready datasets and generate business insights using SQL.

## 🎯 Business Problem

The business wants to understand:

- How much revenue is being generated?
- How are sales changing month by month?
- Which countries generate the most revenue?
- Which customers contribute the most revenue?
- Which products generate the highest revenue?
- What is the average order value?

## 📂 Dataset

**Dataset:** Online Retail II

**Period analyzed:** Year 2009–2010

### Dataset Details

- Raw Rows: 525,461
- Columns: 8

| Country | Customer country |
